# Simulate 应用

`simulate` 是 MuJoCo 的功能完整的交互式应用。它使用跨平台的 GLFW 库打开 OpenGL 窗口，并在其中渲染仿真状态。内置帮助、仿真统计、性能分析器、传感器数据图表。模型文件可通过命令行参数指定，也可在运行时通过拖放功能加载。下面是 simulate 运行时的屏幕截图：
