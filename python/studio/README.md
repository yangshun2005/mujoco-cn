# MuJoCo Studio Python 绑定

[![PyPI 版本][pypi-badge]][pypi]

[pypi]: https://pypi.org/project/mujoco-studio/

本包为 [MuJoCo](https://mujoco.org) 物理引擎（[GitHub](https://github.com/google-deepmind/mujoco)）提供 MuJoCo Studio 交互式查看器（桌面端和 Web 端）以及 Filament 渲染绑定（`mujoco.studio` 和 `mujoco.mjrf`）。

安装完整的 `mujoco` 包时会自动安装本包：

```sh
pip install mujoco
```

也可以与 `mujoco-core` 一起直接安装：

```sh
pip install mujoco-studio
```
